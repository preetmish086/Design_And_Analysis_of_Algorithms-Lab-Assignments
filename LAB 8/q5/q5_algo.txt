PSEUDOCODE-
MSIS(A, n)

    for i ← 0 to n-1
        dp[i] ← A[i]

    answer ← A[0]

    for i ← 1 to n-1

        for j ← 0 to i-1

            if A[j] < A[i]
                dp[i] ← max(dp[i],
                            dp[j] + A[i])

        answer ← max(answer, dp[i])

    return answer


COMPLEXITY-
Time  = O(n²)
Space = O(n)
