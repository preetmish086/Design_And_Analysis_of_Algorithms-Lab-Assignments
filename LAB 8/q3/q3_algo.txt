Longest Common Subsequence
both length of LCS and the actual subsequence reconstruction.

PSEUDOCODE-
LCS(X, Y, m, n)

    for i ← 0 to m
        dp[i][0] ← 0

    for j ← 0 to n
        dp[0][j] ← 0

    for i ← 1 to m
        for j ← 1 to n

            if X[i-1] = Y[j-1]
                dp[i][j] ← dp[i-1][j-1] + 1

            else
                dp[i][j] ← max(dp[i-1][j],
                               dp[i][j-1])

    return dp[m][n]


COMPLEXITY-
Time  = O(mn)
Space = O(mn)
Traceback takes O(m+n)
