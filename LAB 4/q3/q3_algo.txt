To find a set of k elements in S that add up to T.
we need a time complexity of O(n^k-1.log n)

ALGORITHM-

Step 1 - Sort

Sort S using merge sort.

Step 2 - Choose k-1 elements

Generate combinations of k-1 elements using recursion.

Step 3 - Calculate required element

If the selected elements have  sum:
required=T−sum

Step 4 - Binary search

Search for required in the sorted array.

If found, check that we aren't using the same array element twice.
