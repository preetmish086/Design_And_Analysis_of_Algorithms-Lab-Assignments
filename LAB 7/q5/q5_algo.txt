Algorithm

The target moves to an adjacent position after every shot, so its parity changes after every move.

For n > 2, shoot the spots from 2 to n-1, and then come back from n-1 to 2.

For n = 2, shoot spot 1 twice.

Pseudocode
Algorithm MovingTarget(n)

    if n = 2 then
        print 1
        print 1
        return
    end if

    for i ← 2 to n-1 do
        print i
    end for

    for i ← n-1 down to 2 do
        print i
    end for

End Algorithm
Example

For n = 6:

2 3 4 5 5 4 3 2

Number of shots:

$$ 2(n-2) $$
Complexity
Time: O(n) because we generate O(n) shots.
Space: O(1) extra space if the shots are printed directly.
