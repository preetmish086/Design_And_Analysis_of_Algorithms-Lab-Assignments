ALGORITHM-

1. Generate N random elements.
2. Store the elements in a file.
3. Read the elements from the file.
4. Select a pivot.
5. Partition the array around the pivot.
6. Recursively apply Quick Sort to the left subarray.
7. Recursively apply Quick Sort to the right subarray.
8. Display/store the sorted array.


PSEUDOCODE-

QUICKSORT(A, low, high)

    if low < high

        p ← PARTITION(A, low, high)

        QUICKSORT(A, low, p - 1)

        QUICKSORT(A, p + 1, high)

PARTITION(A, low, high)

    pivot ← A[high]

    i ← low - 1

    for j ← low to high - 1

        if A[j] ≤ pivot

            i ← i + 1
            swap A[i], A[j]

    swap A[i + 1], A[high]

    return i + 1


TIME COMPLEXITY-
Average Case: O(n log n)
Worst Case: O(n^2)


SPACE COMPLEXITY-
Average: O(n log n)
