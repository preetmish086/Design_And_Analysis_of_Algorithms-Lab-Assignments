ALGORITHM-
The program follows a three-phase approach:

1. **Phase I — Combination:** Maintain the active nodes in their original order. Repeatedly select a minimum-weight compatible pair and merge it into a new internal node.
2. **Phase II — Level Assignment:** Traverse the combination tree to determine the depth of each original leaf.
3. **Phase III — Alphabetic Tree Reconstruction:** Process leaves in their original order and use a stack to combine adjacent subtrees according to their levels, preserving the order of the leaves.

Finally, print the alphabetic tree and calculate its weighted path cost.


PSEUDOCODE-
HuTucker(weights, n)
    create one leaf node for each weight in original order

    while more than one active node remains:
        find the minimum-weight compatible pair
        merge the pair into a new internal node
        update the active-node sequence

    determine the level of each original leaf

    process original leaves from left to right
    use a stack to reconstruct the alphabetic tree

    calculate and print sum(weight[i] * depth[i])


COMPLEXITY-
Time- O(n^3)
Space- O(n)
