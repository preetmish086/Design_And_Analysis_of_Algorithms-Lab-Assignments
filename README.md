### Lab 9 — Greedy Design Paradigm

1. **Fractional Knapsack with Deterioration Rate** — Optimize item selection and scheduling when item values decrease over time.
2. **Huffman Coding and Canonical Codebooks** — Construct optimal prefix codes from symbol frequencies and represent the resulting codebook canonically.
3. **Minimum Refuelling Stops** — Minimize the number of refuelling stops required to reach a destination.
4. **Minimum-Cost Connection of Sticks** — Repeatedly combine sticks to minimize total connection cost.
5. **Candy Distribution** — Assign candies according to ratings while satisfying neighboring constraints.
6. **String Reorganization with K-Distance Separation** — Rearrange characters so identical characters are separated by at least the required distance.
7. **Minimize Deviation in an Array** — Reduce the difference between maximum and minimum values using allowed number transformations and a max-heap.
8. **Meeting Rooms** — Determine the minimum number of rooms required for overlapping meetings.
9. **Hu–Tucker Greedy Simulation** — Construct an optimal alphabetic binary tree while preserving the original order of the leaves.
10. **Greedy Shortest Superstring** — Repeatedly merge strings using overlaps and study the resulting superstring and the limitations of the greedy approach.
