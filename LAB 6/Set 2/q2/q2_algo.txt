For an n × n matrix:

(i) Matrix Addition

ALGORITHM-
Traverse every matrix element.
Add corresponding elements.
Store the result.

PSEUDOCODE-
MATRIX_ADD(A, B, C, n)

1. For i ← 0 to n-1
       For j ← 0 to n-1
           C[i][j] ← A[i][j] + B[i][j]

COMPLEXITY-
Time: O(n²)
Space: O(n²) for result matrix


(ii) Matrix Multiplication

PSEUDOCODE-
MATRIX_MULTIPLY(A, B, C, n)

1. For i ← 0 to n-1
       For j ← 0 to n-1
           C[i][j] ← 0

           For k ← 0 to n-1
               C[i][j] ← C[i][j] + A[i][k] × B[k][j]

COMPLEXITY-
Time: O(n³)
Space: O(n²)


(iii) Checking Zero Matrix

PSEUDOCODE-
IS_ZERO(A, n)

1. For i ← 0 to n-1
       For j ← 0 to n-1
           If A[i][j] ≠ 0
               Return FALSE

2. Return TRUE

COMPLEXITY-
Time: O(n²)
Space: O(1)


(iv) Checking Symmetric Matrix

A matrix is symmetric if:

A[i][j] = A[j][i]

for every i,j.

PSEUDOCODE-
IS_SYMMETRIC(A, n)

1. For i ← 0 to n-1
       For j ← i+1 to n-1
           If A[i][j] ≠ A[j][i]
               Return FALSE

2. Return TRUE

COMPLEXITY-
Time: O(n²)
Space: O(1)


(v) Determinant

Using Gaussian elimination.

ALGORITHM-
Copy the matrix.
For each diagonal element, select a suitable pivot.
Use the pivot to eliminate elements below it.
The determinant is the product of the diagonal elements.
Account for row swaps by changing the sign.

PSEUDOCODE-
DETERMINANT(A, n)

1. Copy A into B
2. det ← 1

3. For i ← 0 to n-1

       Find pivot row p

       If no non-zero pivot exists
           Return 0

       If p ≠ i
           Swap rows p and i
           det ← -det

       det ← det × B[i][i]

       For j ← i+1 to n-1
           factor ← B[j][i] / B[i][i]

           For k ← i+1 to n-1
               B[j][k] ← B[j][k] - factor × B[i][k]

4. Return det

COMPLEXITY-
Time: O(n³)
Space: O(n²)


(vi) In-place Transpose

PSEUDOCODE-
TRANSPOSE(A, n)

1. For i ← 0 to n-1
       For j ← i+1 to n-1
           Swap A[i][j] and A[j][i]

COMPLEXITY-
Time: O(n²)
Extra Space: O(1)


(vii) Eigenvalues and Eigenvectors

For a general matrix, eigenvalues and eigenvectors can be computed using the QR algorithm.

The QR algorithm repeatedly decomposes:

A = QR

and then computes:

A_{new}=RQ

After sufficient iterations, the diagonal elements approach the eigenvalues.

PSEUDOCODE-
EIGEN_QR(A, n)

1. Repeat for a fixed number of iterations

       Compute QR decomposition:
           A = Q × R

       A ← R × Q

2. Eigenvalues ← diagonal elements of A

3. Eigenvectors are obtained from the accumulated
   Q matrices.

COMPLEXITY-

For a dense n × n matrix:

One QR decomposition: O(n³)
A fixed/convergent number of iterations gives approximately O(n³) for the standard complexity analysis.

Space: O(n²).

In an actual numerical implementation, the number of QR iterations depends on convergence, so the practical running time can be expressed more precisely as O(k n³) for k iterations.
