Given an unsorted array of n integers.

(i) Finding Maximum-

ALGORITHM-
1. Set max = A[0].
2. Traverse the array from index 1 to n-1.
3. If A[i] > max, update max.
4. Return max.

PSEUDOCODE-
FIND_MAX(A, n)

1. max ← A[0]

2. For i ← 1 to n-1 do
       If A[i] > max
           max ← A[i]

3. Return max

COMPLEXITY ANALYSIS-
Time: O(n)
Space: O(1)


(ii) Finding First and Second Largest

ALGORITHM-

Maintain two variables, largest and second.

Initialize both using the first two elements.
Traverse the remaining elements.
If the current element is greater than largest, update both values.
Otherwise, if it is greater than second, update second.

PSEUDOCODE-
FIND_TWO_LARGEST(A, n)

1. largest ← -∞
2. second ← -∞

3. For i ← 0 to n-1 do
       If A[i] > largest
           second ← largest
           largest ← A[i]
       Else if A[i] > second AND A[i] ≠ largest
           second ← A[i]

4. Return largest, second

COMPLEXITY ANALYSIS-
Time: O(n)
Space: O(1)


(iii) Finding Mean

ALGORITHM-
Initialize sum = 0.
Traverse the array and add every element to sum.

Calculate:

mean={sum}/{n}

PSEUDOCODE-
FIND_MEAN(A, n)

1. sum ← 0

2. For i ← 0 to n-1 do
       sum ← sum + A[i]

3. Return sum / n
Complexity Analysis
Time: O(n)
Space: O(1)


(iv) Finding Median

For an unsorted array, first sort it.

ALGORITHM-
Sort the array in ascending order.

If n is odd:

median=A[n/2]

If n is even:

median={A[n/2-1]+A[n/2]}/{2}

PSEUDOCODE-
FIND_MEDIAN(A, n)

1. Sort A in ascending order

2. If n is odd
       median ← A[n/2]
   Else
       median ← (A[n/2 - 1] + A[n/2]) / 2

3. Return median

COMPLEXITY ANALYSIS-
Sorting: O(n log n)
Accessing median: O(1)
Overall: O(n log n)


(v) Finding Standard Deviation

PSEUDOCODE-
FIND_STD_DEV(A, n)

1. mean ← FIND_MEAN(A, n)
2. sum ← 0

3. For i ← 0 to n-1 do
       sum ← sum + (A[i] - mean)²

4. Return sqrt(sum / n)

COMPLEXITY ANALYSIS-
Time: O(n)
Space: O(1)


(vi) Finding Mode

For an unsorted array, compare every element with every other element.

PSEUDOCODE-
FIND_MODE(A, n)

1. maxCount ← 0
2. mode ← A[0]

3. For i ← 0 to n-1 do
       count ← 0

       For j ← 0 to n-1 do
           If A[i] = A[j]
               count ← count + 1

       If count > maxCount
           maxCount ← count
           mode ← A[i]

4. Return mode

COMPLEXITY ANALYSIS-

Two nested loops are used.

Time: O(n²)
Space: O(1)


(vii) Removing All Duplicates

ALGORITHM-
For every element, check whether it already exists in the portion containing unique elements. If not, append it.

PSEUDOCODE-
REMOVE_DUPLICATES(A, n)

1. newSize ← 0

2. For i ← 0 to n-1 do
       duplicate ← FALSE

       For j ← 0 to newSize-1 do
           If A[i] = A[j]
               duplicate ← TRUE
               Break

       If duplicate = FALSE
           A[newSize] ← A[i]
           newSize ← newSize + 1

3. Return newSize

COMPLEXITY ANALYSIS-
Time: O(n²)
Space: O(1) auxiliary space


(viii) Reversing the Array

PSEUDOCODE-
REVERSE(A, n)

1. i ← 0
2. j ← n-1

3. While i < j do
       Swap A[i] and A[j]
       i ← i + 1
       j ← j - 1

COMPLEXITY ANALYSIS-
Time: O(n)
Space: O(1)


(ix) Partitioning with Respect to a Pivot

ALGORITHM-
Select a pivot.
Maintain an index pos.
Traverse the array.
Whenever A[i] >= pivot, place it at pos.
The remaining elements are less than the pivot.

PSEUDOCODE-
PARTITION(A, n, pivot)

1. pos ← 0

2. For i ← 0 to n-1 do
       If A[i] ≥ pivot
           Swap A[i] and A[pos]
           pos ← pos + 1

3. Return pos

COMPLEXITY ANALYSIS-
Time: O(n)
Space: O(1)
