ALGORITHM-
1. Read the number of items n.
2. Read the weight and profit of each item.
3. Read the knapsack capacity W.
4. Create a DP table dp[n+1][W+1].
5. Initialize row 0 and column 0 to 0.
6. For each item i and capacity w:
7. If weight[i] <= w, choose the maximum of:
        excluding the item
        including the item
8. Otherwise, exclude the item.44
9. The maximum obtainable profit is dp[n][W].


PSEUDOCODE-
KNAPSACK(n, weight[], profit[], W)

1. Create dp[0...n][0...W]

2. For w ← 0 to W do
       dp[0][w] ← 0

3. For i ← 0 to n do
       dp[i][0] ← 0

4. For i ← 1 to n do
       For w ← 1 to W do

           If weight[i] ≤ w then
               dp[i][w] ← max(
                   dp[i-1][w],
                   profit[i] + dp[i-1][w-weight[i]]
               )
           Else
               dp[i][w] ← dp[i-1][w]

5. Return dp[n][W]


COMPLEXITY ANALYSIS-
Time Complexity: O(nW)
Space Complexity: O(nW)
