ALGORITHM-
1. Read the value of n.
2. If n = 0, return 0.
3. If n = 1, return 1.
4. Create an array dp of size n + 1.
5. Set dp[0] = 0 and dp[1] = 1.
6. For each i from 2 to n, calculate:
        dp[i] = dp[i-1] + dp[i-2] $$
7. Print dp[n].


PSEUDOCODE-
FIBONACCI(n)

1. If n = 0
       return 0

2. If n = 1
       return 1

3. Create array dp[0...n]

4. dp[0] ← 0
5. dp[1] ← 1

6. For i ← 2 to n do
       dp[i] ← dp[i-1] + dp[i-2]

7. Return dp[n]


COMPLEXITY ANALYSIS-
Time Complexity: O(n)
Space Complexity: O(n)


**SPACE OPTIMIZED** 

ALGORITHM-
1. Read n.
2. If n = 0, return 0.
3. Initialize:
4. prev2 = 0 → F(0)
5. prev1 = 1 → F(1)
6. For i from 2 to n:
7. curr = prev1 + prev2
8. prev2 = prev1
9. prev1 = curr
10. Return prev1.


PSEUDOCODE-
FIBONACCI(n)
1. If n = 0
       return 0
2. prev2 ← 0
3. prev1 ← 1
4. For i ← 2 to n do
       curr ← prev1 + prev2
       prev2 ← prev1
       prev1 ← curr
5. Return prev1


COMPLEXITY ANALYSIS-
Time Complexity: O(n)
Space Complexity: O(1)
