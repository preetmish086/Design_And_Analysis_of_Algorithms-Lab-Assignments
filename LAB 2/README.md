## Question 2 — Merge Sort vs Modified 3-way Merge Sort

### Objective

Compare the standard **2-way Merge Sort** with a modified version of Merge Sort that divides the input array into three parts instead of two.

The modified algorithm recursively sorts the three parts and combines them using a **3-way merge**.

### Concepts Used

* Divide and Conquer
* Merge Sort
* Recursive Algorithms
* 2-way Merge
* 3-way Merge
* Recurrence Relations
* Experimental Performance Analysis

### Standard 2-way Merge Sort

The standard Merge Sort divides the array into two approximately equal halves, recursively sorts both halves, and then merges the two sorted halves.

The recurrence relation is:

```
T(n) = 2T(n/2) + O(n)
```

Therefore:

```
T(n) = O(n log₂ n)
```

### Modified 3-way Merge Sort

The modified version divides the array into three approximately equal parts.

The recurrence relation is:

```text
T(n) = 3T(n/3) + O(n)
```

Therefore:

```text
T(n) = O(n log₃ n)
```

Both algorithms have the overall form:

```text
O(n log n)
```

The 3-way version has fewer levels of recursion because:

```text
log₃ n < log₂ n
```

However, each 3-way merge requires comparisons among three candidates instead of two. Therefore, the actual running time depends on the constant factors involved.
Both are `O(n log n)` asymptotically. The difference in logarithm base affects the constant factor, while the 3-way merge itself has a higher merging cost.  

### Approach

Both algorithms are executed on the **same randomly generated input arrays** for increasing values of `n`.

The execution time of each algorithm is measured and recorded.

The program also verifies that both algorithms correctly sort the input arrays.

### Output

The experiment records:

* Array size `n`
* Execution time of 2-way Merge Sort
* Execution time of modified 3-way Merge Sort

The data is stored in:

```text
Q2/csv/mergesort_data.csv
```

### Graph

The data is imported into Microsoft Excel to create a comparison graph.

The graph represents:

* **X-axis:** Array Size `n`
* **Y-axis:** Execution Time (milliseconds)

The two algorithms compared are:

```text
Classic Merge Sort (2-way)
        vs.
Modified Merge Sort (3-way)
```

## Question 3 — Merging k Sorted Arrays

### Objective

Given `k` sorted arrays, each containing `n` elements, combine them into a single sorted array containing `kn` elements.

Two different merging approaches are implemented and experimentally compared.

---

### Method 1 — Sequential Merging

The arrays are merged one at a time.

For example:

```text
Array 1 + Array 2
       ↓
  2n elements
       ↓
Result + Array 3
       ↓
  3n elements
       ↓
Result + Array 4
       ↓
      ...
```

The `i`-th merge processes approximately `i × n` elements.

Therefore:

```text
T(n,k) = O(n) + O(2n) + O(3n) + ... + O(kn)
```

Hence:

```text
T(n,k) = O(nk²)
```

---

### Method 2 — Pairwise Merging

The arrays are merged in pairs.

For example:

```text
k arrays
   ↓
k/2 pairs
   ↓
k/2 arrays of size 2n
   ↓
k/4 pairs
   ↓
k/4 arrays of size 4n
   ↓
     ...
   ↓
1 array of size kn
```

There are approximately `log₂ k` merging rounds.

Each round processes a total of `kn` elements.

Therefore:

```text
T(n,k) = O(nk log k)
```

### Concepts Used

* Divide and Conquer
* Merge Algorithm
* Sequential Merging
* Pairwise Merging
* Recursion
* Asymptotic Analysis
* Experimental Performance Analysis

### Approach

For a fixed value of `n`, the number of arrays `k` is increased gradually.

Both merging methods are executed on the same collection of sorted arrays.

The execution time of both methods is recorded and compared.

The final arrays are also checked to ensure that the merging operations produce correctly sorted output.

### Output

The experiment records:

* Number of arrays `k`
* Execution time of Method 1 — Sequential Merging
* Execution time of Method 2 — Pairwise Merging

The data is stored in:

```text
Q3/csv/kway_data.csv
```

### Graph

The data can be imported into Microsoft Excel to create a comparison graph.

The graph represents:

* **X-axis:** Number of arrays `k`
* **Y-axis:** Execution Time (milliseconds)

The two methods compared are:

```text
Method 1: Sequential Merging
        vs.
Method 2: Pairwise Merging
```
